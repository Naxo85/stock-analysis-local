## Policy and reliability

config/codex_analysis.json controls models and execution/freshness settings.
Luna high reviews current and full Sol reports and updates supported routine
technical changes. Critical/material fundamental change, uncertainty, hard
guard or due ITV escalates to Sol high. Hard guards, ITV and full runs skip Luna.
Failed/missing/stale/truncated data blocks before calling any model.

ITV: maximum age 5 US sessions for ALL tickers, including tracking, per user
request. At that age Sol is required; a data/provider/quota failure leaves the
review overdue/pending, never renews the report with Luna. NYSE holidays and early
closes are handled; extraordinary closures are configurable. Only a validated
Sol-high report resets age. Oldest reports within ownership/tier go first.
Every required material-change/age-based review can run; there is no daily
report or ITV allowance. Failures remain visible and do not refresh report age.

Execution controls: 6 concurrent models and finite per-call timeouts (Luna
240 seconds, Sol 1200 seconds, separate waits per ticker if both are needed).
There is no input-character cap, reserved quota percentage or aggregate
call/report/ITV/token cutoff. Token/cache accounting remains recorded. Quota is shared
with other Codex work. Exhausted/unknown quota blocks real new calls; unknown
usage makes that ticker's call fail without retry, not a global circuit.
No API key, credit purchase or automatic model fallback.

Prompt-cache optimization follows official documentation's exact-prefix rule:
https://developers.openai.com/api/docs/guides/prompt-caching . Schema, instructions,
tools and effort stay constant per role; no unsupported CLI caching switches
were added. Actual cache hits are measured, never guaranteed or treated as a
discount on subscription quota. Local verdict/research caches are separate.

Stable content-hashed instruction files form the common prompt prefix;
ticker data is a separate user message. For this dedicated text generator,
model_instructions_file replaces coding-agent base instructions. Shell/web/apps/
delegation are disabled and sandbox is read-only. Sol can use read-only web
research only when explicitly enabled; Luna cannot. Skills catalog is capped
for this dedicated generator, memories/remote catalog disabled, and notify=[]
prevents the inherited Windows notification command-length failure. These are
invocation-scoped overrides; global configuration/auth remains unchanged.

prompts/daily_maintenance.md plus the FULL source rubric. Historical revision-1/2
