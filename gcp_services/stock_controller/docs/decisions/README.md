# Architecture decisions

Este directorio guardara decisiones arquitectonicas concretas cuando sea
necesario explicar su contexto, alternativas y consecuencias.

No se crea una decision para rellenar el directorio. Cada documento debe estar
ligado a una eleccion real discutida o a una necesidad tecnica demostrada.

Formato:

```text
NNNN-titulo-breve.md
```

Estado permitido: `proposed`, `accepted`, `superseded` o `rejected`.

Decisiones:

- `0001-layout-declarativo-de-google-sheets.md`
- `0002-refresco-cloud-de-mercado.md`
- `0003-tres-superficies-y-orden-automatico.md`
- `0004-dos-tablas-balanceadas.md`
